fst · 外链发射台本地半自动化外链发布

● 已连接
锚文本目标 URL平台状态落地 URL（点击编辑）操作
还没有任务，点击右上角「＋ 新建任务」创建第一条外链任务
模板支持 Spin 语法 {选项1|选项2} 与变量 {锚文本} {目标URL} {日期}，可嵌套一层
规则告诉油猴脚本「当前网站上标题/正文/链接该填进哪个输入框」。域名支持通配符，如 *.wordpress.com

使用流程

  1. 安装油猴脚本：浏览器先安装 Tampermonkey 扩展，然后打开 http://127.0.0.1:3456/fst-helper.user.js，Tampermonkey 会自动弹出安装页。
  2. 创建任务：在「外链任务」页新建任务（目标 URL + 锚文本 + 模板），或在「平台规则」页配置目标站点的填充规则。
  3. 开始发布：登录目标平台进入发帖页 → 页面右下角出现「fst 助手」面板 → 拉取任务 → 一键填充 → 人工检查内容、过验证码、自己点击提交（脚本永不代替你提交）。
  4. 回填记录：发布成功后点面板上的「标记已发布」，粘贴落地 URL，管理台状态自动更新。
  5. 收录检测：回到管理台勾选已发布任务，点「检测收录」。自动检测不可靠时会得到「未确认」，点「打开检测页」人工确认。

注意事项

  • 脚本激活条件：当前网站域名命中「平台规则」且规则未停用；「通用启发式（兜底）」规则会对所有站点生效，可按需停用。
  • 填充不准确时，用面板上的「拾取选择器」功能点选目标输入框，把得到的选择器填进对应平台规则里。
  • 所有数据仅保存在本机 data/db.json，脚本只与本机管理台通信。
  • 自动收录检测依赖 Bing 的可用性，触发反爬时会得到「未确认」，人工复核是正式流程的一部分。
